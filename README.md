# InfoSegura - Landing Page (prototipo académico)

## Archivos
- `InfoSegura.html`: estructura y secciones de la página.
- `InfoSegura.css`: identidad visual, estilos y adaptación responsive.
- `InfoSegura.js`: navegación, accesibilidad e interacciones.

## Cómo ejecutar
1. Coloca los tres archivos en la misma carpeta.
2. Abre `InfoSegura.html` en un navegador moderno.
3. Opcional: abre la carpeta con Visual Studio Code y usa Live Server.

## Funcionalidades demostrativas
- Navegación Inicio, Historial, Aprende y Ayuda.
- Campo de texto, contador y validación.
- Adjuntar archivo con vista previa y límite de 15 MB.
- Revisión heurística local de señales textuales.
- Historial guardado en `localStorage`.
- Aumento/disminución de texto y alto contraste.
- Dictado y lectura en voz alta si el navegador admite las API.
- Descarga de un reporte `.txt`.
- Sección educativa con recomendaciones.
- Formulario de ayuda con validación local.
- Diseño responsive para móvil y escritorio.

## Limitaciones que deben declararse
Esta versión es frontend y de demostración. Las reglas de texto no verifican hechos ni consultan fuentes automáticamente. Adjuntar archivos no ejecuta análisis de autenticidad ni detección de deepfakes. El formulario de ayuda no envía información a un servidor. Para esas funciones se requiere backend e integración con servicios especializados.

Antes de la entrega, el equipo debe relacionar cada interacción con los criterios de aceptación de las 30 HU definitivas y probarlas en los navegadores y tamaños de pantalla objetivo.
